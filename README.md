# ¡Vamos! — Испанский с нуля
Русскоязычный учебник испанского (A0–A1): 32 урока, словарь, игры, произношение, подробные подсказки, XP и повторение слов.

**Ссылка на сайт после публикации GitHub Pages:** https://makarken.github.io/spain_teaching/

**Установка на iPhone:** откройте сайт в Safari → Поделиться → На экран Домой → Добавить.

Прогресс сохраняется в браузере устройства, без синхронизации между устройствами. Экспорт/импорт прогресса в настройках позволяет перенести данные. Микрофон поддерживается не всеми браузерами; голосовое воспроизведение зависит от наличия испанского голоса на устройстве. Встроенные грамматические объяснения не используют ИИ. Веб-приложение способно работать с ранее закэшированными файлами без интернета.

Для настройки публикации: GitHub → Settings → Pages → Deploy from a branch → main → /(root).
